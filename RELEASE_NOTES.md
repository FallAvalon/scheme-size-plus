# Size Plus (S+) 0.5.0 [v160.7]

Тестовый выпуск для настольной Mindustry **160.7**.

Схемы и быстрый доступ, импорт изображений, строительные инструменты, визуальные слои и локальный прогноз маршрутов противников по клеткам.

- Удержание колёсика: шесть групп схем по тегам, выбор направлением, миниатюры и обычное размещение в Plus/God.
- God: компактная панель боя с фазой/таймером/боссом и быстрыми командами.
- Колесо над картой меняет зум при открытых панелях и окнах выбора мода; над списками прокручивает список.
- Частые действия без подтверждений по умолчанию; переключатель возвращает подтверждения.
- God: прямой выбор Пол / Руда / Стены, природные стены карты, применение и отмена.
- Alt + Mouse Back также на клиенте сервера через обычный snapshot; strict/античит может исправить позицию.
- Подписанные разделы, сворачивание подписей и компактные панели.
- Карточки схем с превью, вкладки Библиотека / С карты.
- Карточки юнитов, конкретная кнопка убийства группы, шаги создания и предпросмотр точки на карте. Исправлена отмена правой кнопкой.

Установка: импортировать `scheme-size-plus.jar` через меню модификаций и перезапустить игру. Обычно нужна только одна редакция.

Сборка/check, упаковка, отдельные редакции и совместная загрузка проверены на Windows. Полный отчёт: https://github.com/FallAvalon/scheme-size/blob/eddafac94ae55497d12acf87b886bce49c276a0b/reports/21_held_menu_and_combat.md

Linux, WAN и физический OS-ввод не проверены. Полный паритет O279 не заявлен. Android не поддерживается. Смерть юнитов необратима и может вызвать побочный урон.

Вложения: **scheme-size-plus.jar** и **SHA256SUMS.txt**. Исходники: https://github.com/FallAvalon/scheme-size/tree/eddafac94ae55497d12acf87b886bce49c276a0b
